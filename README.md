# Cipher Path · مسار الشيفرة · 码道

Learn software engineering and cybersecurity in Arabic or English, with professional Chinese for every topic.

- **Two tracks, 24 modules** – 96 lessons, 144 quiz questions, practice exams with a per-module breakdown, certificates.
- **Labs** – 24 JavaScript code labs checked by automatic tests in a sandboxed worker; phishing detective, log hunter, secure code review, cipher workshop (12 capture-the-flag challenges), firewall simulator (generated rules, 3 levels), password & SHA-256 lab; a daily challenge.
- **Tech Chinese** – 241 terms with pinyin (checked against CC-CEDICT), spaced repetition, 96 dialogue lines, 10 workplace conversations (stand-ups, code review, incident response, audits, pen-test scoping).
- **Fun and identity** – Chinese lacquer design (cinnabar, gold, jade, rice paper), Lóngbǎo the debugging dragon with 20 jokes, a bug boss to defeat in every module, combo streaks with firecrackers, a daily red envelope 红包 and fortune stick 求签, 17 seal achievements and kung-fu ranks from 码徒 to 码圣.
- **Quick games** – term sprint, bits & hex, ports & services.
- Dark and light themes, full RTL, offline single-file web app inside an Expo iPhone shell with RevenueCat and AdMob.

Build: `bash scripts/build.sh` → `cp/dist/cipher-path.html`. iPhone: see `docs/BUILD_IOS.md`.
