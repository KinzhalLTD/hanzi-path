# Cipher Path – notes for Claude sessions

Sister app of Hanzi Path (same engine): software engineering + cybersecurity in Arabic and English, with a Chinese track for every topic.
Lives on the `cipher-path` branch of KinzhalLTD/hanzi-path (its own history; not merged with `main`).

- Source in `cp/src/*.js` + `cp/src/styles.css`; never edit `cp/dist/` by hand. Module order is `ORDER` in `scripts/build_cp.py`. Build: `bash scripts/build.sh` (must print "build OK").
- Curriculum: `content/mod_*.tsv` (format in the header of `mod_1_se.tsv`: @module, L lesson, Q quiz, T Chinese term, D dialogue). Rebuild data with `python3 -I scripts/curr_build.py "$PWD" <cedict_base.json>` (must print `errors 0`; checks counts, distinct options, pinyin vs CC-CEDICT). Term ids are positional (`1000 + module index*100 + j`, SRS progress keyed by them): append new modules and terms at the END only.
- Conversations: `content/talk_soft.tsv` (from Hanzi Path) and `content/talk_sec.tsv`; rebuild with `python3 -I scripts/talk_build.py "$PWD" <cedict_base.json>` (errors 0).
- Code labs: `cp/src/labs_code.js` (tests are [expression, expected]; the reference solution must pass and the starter must fail – `scripts/test_app.py` checks every lab in the worker). Security labs content: `cp/src/labs_sec.js` (PHISH flags `[[text|why ar|why en]]`, LOGS `bad` line indexes, REVIEW `bad` line + `v` key in VULNS, CTF flags `CP{...}` solvable with the workbench tools).
- Identity & fun (`cp/src/fun.js`): Chinese lacquer palette (cinnabar `--red`, gold `--gold`, jade, porcelain blue; light = rice paper), brush font `--f-brush` (Ma Shan Zheng, falls back to a serif Chinese font offline). Mascot 龙宝 `dragon(mood,size)`; JOKES/QUIP_OK/QUIP_BAD/FORTUNES/TAUNTS are bilingual pairs; every module key needs an entry in BOSSES (module quiz = boss fight: hearts = n − ceil(0.7n) + 1, so losing the fight = failing 70%). Daily 红包 (`S.hbDay`) and 求签 (`S.fortuneDay`) are seeded by date; seals in BADGES are checked by `checkBadges()` after XP; combo via `comboHit(ok)`.
- Polish (`cp/src/polish.js`, loaded right after core): Web Audio instruments (guzheng `pluck` on the pentatonic `note(i)`, `wood`, `drum`, `bell`, `gongS`, `whoosh`) behind the `SFX` names; Chinese-style line icons added to `ICON` and enamel medallions `ico(name,tone,size)` (tones red/gold/jade/blue/ink); daily quests `quests()` / `questEvent(kind,n)` (kinds right, lab, term, boss, combo, xp, lesson, talk) with the 宝箱 chest; week-of-lanterns `weekWidget()` from `S.days`.
- Canva artwork: PNGs in `art/canva/` (name = key, e.g. `longbao_happy`, `longbao_win`, `longbao_sad`, `longbao_cool`, `boss_<module key>`) are compressed to WebP and embedded by `build_cp.py` as `ART`; `dragon(mood)` uses the art when present and the SVG otherwise. The sandbox only receives 200-px copies from the Canva connector (Canva's download hosts are blocked), so art is used at small sizes.
- Journey (`cp/src/journey.js`, routes `track`/`gaterun`): each track = 4 chapters (`CHAPTERS`, 3 modules each, by position in the track) with a gate (关) test: 10 questions from the chapter, pass 80% → crown in `S.gates[tr+ci]` + 50 bits. Labelled back/next buttons use `navPair(backLabel,nextLabel,{bid,nid})` with `fwdA()/backA()` arrows that follow RTL.
- Music (`cp/src/music.js`): live low guzheng soundtrack (koto + pizzicato samples in `art/samples.json`, FluidR3 GM CC BY 3.0, emitted lazily as `SAMPLES()`), D-major pentatonic phrases with slides, sine drone, reverb; `S.music` false = off, `S.mv` low/mid; starts on first tap, pauses in background, `musDuck()` while voice plays. Toggle = music chip in the top bar and Me → Guzheng music.
- Accounts (`cp/src/account.js` + `mobile/src/firebase.js` + CipherBridge `auth:*`/`sync:*`): Sign in with Apple / Google via Firebase project `hanzi-path-64170` (shared with Hanzi Path), progress in Firestore `cipher_users/{uid}` (never `users`). Offered in onboarding (step 3) and once after the first module; guests get everything. Setup: `docs/ACCOUNTS.md`.
- Profitability (`cp/src/profit.js`, design in `docs/PROFITABILITY.md`): paywall(src) with Free vs PRO table and 7-day trial on yearly (only if `window.__trialOk`), `breakPoint(kind,nav)` (first module → sign-up, third → milestone paywall, else interstitial), opt-in rewarded ads capped at 5/day (revive retries the missed question, double bits, extra exam, +25 bits), shop with freeze/revive token/exam ticket and bit packs (consumables `space.kinzhal.cipherpath.bits.*`). Track events with `track(ev,props)`.
- Bilingual UI: every string in `cp/src/i18n.js` (both languages, same keys – the test checks) or inline `isAr()?…:…`. Check RTL.
- Theme: dark default / light via `S.theme`, tokens in `styles.css`; dark-only surfaces (terminal, code, feedback, lab heroes) are in the `:is(...)` always-dark scope. Check with `python3 scripts/audit_theme.py mobile/assets/web/cipher-path.html OUT` → `hard {'dark': 0, 'light': 0}`.
- Free tier: first 3 modules per track, first 3 code labs per track, first 3 rounds of phishing/logs/review, first 4 cipher challenges, firewall level 1, 1 exam a day, first conversation per field. PRO only from the native `{type:'pro'}` message (RevenueCat entitlement `pro`).
- iPhone app: Expo SDK 58 in `mobile/` (bundle `space.kinzhal.cipherpath`). `npm run sync-web` adds the phone shell to `mobile/assets/web/cipher-path.html` – run tests/audits on that file. Before a build: `npm run check:store` (owner items: AdMob ids, RevenueCat key, Google iOS client id + REVERSED_CLIENT_ID) and `npx expo export --platform ios`. Steps in `docs/BUILD_IOS.md`; ads `docs/ADS.md`; purchases `docs/IN_APP_PURCHASES.md`; store listing and review notes `docs/APP_STORE_SUBMISSION.md`; website (privacy/terms/support, app-ads.txt) in `website/` → Firebase Hosting site `cipher-path-kinzhal`.
- Tests after changes: `python3 scripts/test_app.py mobile/assets/web/cipher-path.html OUT` (errors []), `python3 scripts/audit_layout.py mobile/assets/web/cipher-path.html OUT` (no overflow/clipping), `scripts/audit_theme.py`.
- Owner works on Windows and prefers copy-paste commands (Google Cloud Shell).
