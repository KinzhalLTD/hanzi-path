# Cipher Path – notes for Claude sessions

Sister app of Hanzi Path (same engine): software engineering + cybersecurity in Arabic and English, with a Chinese track for every topic.
Lives on the `cipher-path` branch of KinzhalLTD/hanzi-path (its own history; not merged with `main`).

- Source in `cp/src/*.js` + `cp/src/styles.css`; never edit `cp/dist/` by hand. Module order is `ORDER` in `scripts/build_cp.py`. Build: `bash scripts/build.sh` (must print "build OK").
- Curriculum: `content/mod_*.tsv` (format in the header of `mod_1_se.tsv`: @module, L lesson, Q quiz, T Chinese term, D dialogue). Rebuild data with `python3 -I scripts/curr_build.py "$PWD" <cedict_base.json>` (must print `errors 0`; checks counts, distinct options, pinyin vs CC-CEDICT). Term ids are positional (`1000 + module index*100 + j`, SRS progress keyed by them): append new modules and terms at the END only. Extra content lives in later files (`mod_5_more_se1.tsv`…`mod_8_more_cy2.tsv`) that continue a module with a `+key` line; question ids are `key#index` (progress in `S.qa`), so questions are append-only too. Rich packs `content/mod_9_NN_<key>.tsv` (one per module, `+key`) add depth cards `X|lesson#|ex|pit|key|ar|en` (real-world example, common mistake, key takeaways – `\n` separates the takeaway bullets; shown after the body paragraphs as `.xcard`), lessons 5–6 and 10 more questions per module; every module now has exactly 100 terms, the maximum the id scheme allows (`1000 + i*100 + j`, j ≤ 99) – never add more. Term lists for bulk adds live in `content/terms_more/*.txt` (`+key`, then `zh|ar|en`); `python3 -I scripts/terms_fill.py "$PWD" <cedict_base.json> FILE [--write]` fills pinyin from CC-CEDICT (`PREF`/`WPREF` pick the reading of polyphonic characters; it reports any still ambiguous), skips duplicates and appends to the rich pack; To swap a weak term in place (same position, same id) use a `OLD>NEW|ar|en` file with `--replace` (`content/terms_more/replace_*.txt`). Quiz quality: `python3 -I scripts/qa_bias.py "$PWD" [--dump PREFIX]` lists questions whose right answer is clearly the longest option (a give-away); fix them with balanced distractors in `content/qa_fix/*.txt` (`key#i|en1|en2|en3||ar1|ar2|ar3`, quick checks `key@lesson|en1|en2||ar1|ar2`) applied by `python3 -I scripts/qa_fix.py "$PWD"` – keep the right answer no longer than the others when you write new questions. Learners can flag a quiz question with ⚑ (`reportQ` → `S.reports`, GA4 `content_report`). Expert review sheets: `python3 -I scripts/review_export.py "$PWD"` → `docs/review/*.csv`; beta plan in `docs/BETA_TEST.md`. Module summary route `msum` (key takeaways + common mistakes + top terms). The term bank renders in pages of 80 (IntersectionObserver). English question text and terms must be unique across modules, and Arabic lines avoid "←" (bidi). Every lesson also needs one fun card and one quick check, in `content/fun_*.tsv` (`+key` then `F|lesson#|emoji|fact/joke/story/myth|ar|en` and `C|lesson#|ar q|en q|ar right|en right|ar wrong1|en wrong1|ar wrong2|en wrong2|ar why|en why`; `=` in an Arabic option cell means "same as English"). Facts there must be true and checkable.
- Lesson flow (`SCREENS.lesson`, route arg `{k,i,s}`; negative `s` counts from the end): one info card per body paragraph (code on the last) → fun card with 龙宝's reaction → quick check with 3 shuffled options (`.lcopt[data-ok]`); Next stays disabled until the right answer (`S.lq['key#i']`), first-try right gives confetti + 3 XP. Segmented step bar `.lsteps`.
- Conversations: `content/talk_soft.tsv` (from Hanzi Path) and `content/talk_sec.tsv`; rebuild with `python3 -I scripts/talk_build.py "$PWD" <cedict_base.json>` (errors 0).
- Code labs: `cp/src/labs_code.js` (tests are [expression, expected]; the reference solution must pass and the starter must fail – `scripts/test_app.py` checks every lab in the worker). Security labs content: `cp/src/labs_sec.js` (PHISH flags `[[text|why ar|why en]]`, LOGS `bad` line indexes, REVIEW `bad` line + `v` key in VULNS, CTF flags `CP{...}` solvable with the workbench tools).
- Identity & fun (`cp/src/fun.js`): Chinese lacquer palette (cinnabar `--red`, gold `--gold`, jade, porcelain blue; light = rice paper), brush font `--f-brush` (Ma Shan Zheng, falls back to a serif Chinese font offline). Mascot 龙宝 `dragon(mood,size)`; JOKES/QUIP_OK/QUIP_BAD/FORTUNES/TAUNTS are bilingual pairs; every module key needs an entry in BOSSES (module quiz = boss fight: hearts = n − ceil(0.7n) + 1, so losing the fight = failing 70%). Daily 红包 (`S.hbDay`) and 求签 (`S.fortuneDay`) are seeded by date; seals in BADGES are checked by `checkBadges()` after XP; combo via `comboHit(ok)`.
- Polish (`cp/src/polish.js`, loaded right after core): Web Audio instruments (guzheng `pluck` on the pentatonic `note(i)`, `wood`, `drum`, `bell`, `gongS`, `whoosh`) behind the `SFX` names; Chinese-style line icons added to `ICON` and enamel medallions `ico(name,tone,size)` (tones red/gold/jade/blue/ink); daily quests `quests()` / `questEvent(kind,n)` (kinds right, lab, term, boss, combo, xp, lesson, talk) with the 宝箱 chest; week-of-lanterns `weekWidget()` from `S.days`.
- Canva artwork: PNGs in `art/canva/` (name = key, e.g. `longbao_happy`, `longbao_win`, `longbao_sad`, `longbao_cool`, `boss_<module key>`) are compressed to WebP and embedded by `build_cp.py` as `ART`; `dragon(mood)` uses the art when present and the SVG otherwise. The sandbox only receives 200-px copies from the Canva connector (Canva's download hosts are blocked), so art is used at small sizes.
- Journey (`cp/src/journey.js`, routes `track`/`gaterun`): each track = 4 chapters (`CHAPTERS`, 3 modules each, by position in the track) with a gate (关) test: 10 questions from the chapter, pass 80% → crown in `S.gates[tr+ci]` + 50 bits. Labelled back/next buttons use `navPair(backLabel,nextLabel,{bid,nid})` with `fwdA()/backA()` arrows that follow RTL.
- Music (`cp/src/music.js`): a real guzheng — 34 recorded plucks in `art/guzheng/` (CC0, Freesound Pufermufin via XSXB-Band-Samples; `index.json` has key, tuning cents, level, dynamic layer), embedded lazily as `GZ_SAMPLES()`. Strings tuned D F G A C → pieces in F gong pentatonic (`GZ_PIECES`: 茉莉花, 送别 + originals) arranged per pass with guzheng techniques (刮奏 glissando, 按音 bends for 4/7, 上滑音 slides, 摇指 tremolo, 吟 vibrato, 流水 left hand), humanised, hall reverb. `S.music` false = off, `S.mv` low/mid; starts on first tap, pauses in background, `musDuck()` while voice plays.
- Mastery (`cp/src/mastery.js`): `qMark` records every answer in `S.qa[key#i]` ({n,w,s}); `fightPick` draws 8 questions per boss fight (up to 3 missed, then unseen, then random) from the 16 per module; Weak spots (route `weak`, home card) re-asks missed questions until answered right twice in a row.
- Accounts (`cp/src/account.js` + `mobile/src/firebase.js` + CipherBridge `auth:*`/`sync:*`): Sign in with Apple / Google via Firebase project `hanzi-path-64170` (shared with Hanzi Path), progress in Firestore `cipher_users/{uid}` (never `users`). Offered in onboarding (step 3) and once after the first module; guests get everything. Setup: `docs/ACCOUNTS.md`.
- Profitability (`cp/src/profit.js`, design in `docs/PROFITABILITY.md`): paywall(src) with Free vs PRO table and 7-day trial on yearly (only if `window.__trialOk`), `breakPoint(kind,nav)` (first module → sign-up, third → milestone paywall, else interstitial), opt-in rewarded ads capped at 5/day (revive retries the missed question, double bits, extra exam, +25 bits), shop with freeze/revive token/exam ticket and bit packs (consumables `space.kinzhal.cipherpath.bits.*`). Track events with `track(ev,props)`.
- Voice cast (`cp/src/voice.js`): `VOICE_CAST` n narrator, p partner, m1–m5 / f1–f3 (gender, Chirp voice, phone pitch/rate). `SCENE_CAST` picks each conversation partner's voice (genders follow the role text), `dlgVoice(moduleIndex,'A'|'B')` the module-dialogue pair, `myVoice()` the learner (Me → Your voice). A conversation opens with the narrator reading the scene title. Studio clips: `python3 scripts/voice_corpus.py cp/dist/cipher-path.html` → `content/voice/corpus.json` (commit it); the owner runs `bash scripts/voice_cloudshell.sh` in Cloud Shell (docs/VOICE.md). Keep `CAST` in `scripts/voice_gen.py` and the native `CAST` in `mobile/src/voice.js` in step. Test: `scripts/test_voice.py`.
- Bilingual UI: every string in `cp/src/i18n.js` (both languages, same keys – the test checks) or inline `isAr()?…:…`. Check RTL.
- Theme: dark default / light via `S.theme`, tokens in `styles.css`; dark-only surfaces (terminal, code, feedback, lab heroes) are in the `:is(...)` always-dark scope. Check with `python3 scripts/audit_theme.py mobile/assets/web/cipher-path.html OUT` → `hard {'dark': 0, 'light': 0}`.
