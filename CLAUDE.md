# Hanzi Path – notes for Claude sessions

- Source lives in `hp/src/*.js`; never edit `hp/dist/` by hand. Build with `bash scripts/build.sh` (must print "build OK").
- Module order and placeholders (`__SAMPLES__`, `__PHOTOS__`, `__CHARS__`, `__STROKES__`, `__SECEXT__`, `__KL__`, `__TANGRAMS__`) are defined in `scripts/build_hp.py`.
- Content: HSK TSV formats are 8 fields `hanzi|pinyin|arabic|english|ex zh|ex pinyin|ex ar|ex en` or 7 fields (no English gloss). After editing, run `bash scripts/merge_all.sh` then build.
- Validate pinyin against CC-CEDICT with `scripts/check_content.py` before merging. Polyphonic characters need hand-checked readings.
- Bilingual UI: every string needs Arabic and English (`hp/src/i18n.js` or inline `isAr()?…:…`). Check RTL layout.
- Run `python3 scripts/regress.py hp/dist/hanzi-path.html /tmp/r.png` and the relevant `scripts/test_*.py` after changes; they must report `errors []`.
- Owner works on Windows and prefers copy-paste commands (e.g. Google Cloud Shell) over click-by-click steps.
- Bundle ID `space.kinzhal.hanzipath`; Firebase project `hanzi-path-64170`.
- In-app purchases: RevenueCat (`mobile/src/purchases.js`), entitlement `pro`. Pro must only come from the native `{type:'pro'}` message, never from cloud sync. Setup steps in `docs/IN_APP_PURCHASES.md`; test with `scripts/test_iap.py`.
- Privacy policy URL is `https://hanzi-path-64170.web.app/privacy.html` (Firebase Hosting, website step).
- Ads: AdMob via `mobile/src/ads.js` (consent → ATT → init), free users only, interstitial at break points (max 6/day), rewarded opt-in. Setup in `docs/ADS.md`; test with `scripts/test_ads.py`.
- iPhone app: Expo SDK 58 project in `mobile/` (follow `mobile/AGENTS.md`: `npx expo install`, never edit `ios/`). It bundles `hp/dist/hanzi-path.html` via `npm run sync-web` (adds the viewport/UTF-8 shell). Before a build run `npm run check:store` and `npx expo export --platform ios`. Build steps in `docs/BUILD_IOS.md`.
- Learning engine v2 (`hp/src/learn.js`): sentence exercises (build/gap/slisten/pinyin/tonepair), contextual pinyin via `alignPy` (sentence pinyin aligned to characters), mastery 0–5 from SRS boxes, adaptive `lessonPlan`, placement test. Journey (`hp/src/journey.js`): chapters per place, gate tests. Test with `scripts/test_learn.py`; layout with `scripts/audit_layout.py` on `mobile/assets/web/hanzi-path.html` (has the phone viewport).
- Workplace conversations (`hp/src/talk.js`, routes `talk`/`talkscene`): content in `content/talk_*.tsv` (P/A/B/X lines, see header of `talk_eng.tsv`). Validate and rebuild data with `python3 -I scripts/talk_build.py "$PWD" <cedict_base.json>` (must print `errors 0`; it checks pinyin against CC-CEDICT and character counts), then build. Test with `scripts/test_talk.py` on the phone-shell HTML.
- Sector vocabulary: `content/sec_*.tsv` (file-name order; a later file may extend an existing `@sector`/`#topic`). Rebuild with `python3 -I scripts/sec_build.py "$PWD" <cedict_base.json>` (must print `errors 0`). Term ids are stable via `content/sector_ids.json` (learner progress is keyed by id): never edit or renumber existing entries, and only append new sectors at the END of `SECTORS` in `hp/src/sectors_data.js` (display order is `SEC_ORDER` in `sectors.js`). Shared pinyin checks live in `scripts/pinyin_check.py` (accepted dictionary variants in `VARIANTS`).
- Performance: big data tables (W, strokes, photos, samples, art, chars, talk, sector ext) are emitted by `build_hp.py` as `<script type="application/json" id="d-*">` blocks; `__json` parses at startup, `__lazy` (a Proxy) parses on first use. Keep new large data out of JS literals. Measure with `python3 scripts/perf_lab.py mobile/assets/web/hanzi-path.html /tmp/p.json` (4x CPU phone profile; `--compare A.json B.json`), and find hot spots with `scripts/perf_profile.py HTML "go('route')"`.
- Feel (`hp/src/feel.js`): haptic tick on tab/primary taps (kinds select/light/medium/success/error, mapped in HanziBridge), staggered screen-enter animation, tap on the active tab scrolls to top. `go()` keeps a history stack (`NAV`) and restores scroll on back; the tab bar stays mounted between screens. Long lists use `content-visibility:auto`.
- Grammar (`hp/src/grammar.js`, routes `grammar`/`gpoint`/`gpractice`): HSK 1–6 syllabus in `content/gram_1.tsv`…`gram_6.tsv` (format in the header of `scripts/gram_build.py`: `#key|pattern|markers|ar|en`, `a:`/`e:` explanations, `>` examples, `!` tip, `x:` wrong|right). Rebuild data with `python3 -I scripts/gram_build.py "$PWD" <cedict_base.json>` (must print `errors 0`), then build. Keys are stable ids (progress `S.gram[key]`): never rename. Pattern slot words (S, V, O, Adj…) need an entry in `GR_SLOT` (Arabic + English); keep English notes out of patterns. Free: all HSK 1 + first 3 points per level. Test with `scripts/test_grammar.py` on the phone-shell HTML.
